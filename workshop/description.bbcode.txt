[h1]中文｜IsoRim 材质与细节分级[/h1]
[b]测试版 0.3.0 · RimWorld 1.7[/b]

为 IsoRim 的普通静态建筑模型提供法线贴图与两／三档 LOD。用烘焙法线表现凹槽、接缝和细小倒角；在拉远镜头时切换预先制作的简化模型。

[b]安装前必读：当前需要配套的 IsoRim API 测试分支。普通工坊版尚缺少所需接口，仅订阅本 Mod 无法启用。请按下方源码仓库的说明配套构建和安装。[/b]

[h2]功能[/h2]
[list]
[*]静态建筑法线贴图，可配置强度与方向。
[*]两档或三档 LOD，按屏幕占比切换，并使用滞回减少临界位置的反复切换。
[*]通过 IsoRim 公开 API 接入；本附加 Mod 不使用 Harmony 补丁或内部反射。
[*]支持 IsoRimZ 的地面层与上层静态建筑；开启楼层不再整体停用扩展。
[*]当前层按屏幕大小分级，可见下层默认最远档（可关闭）；隐藏层暂停 LOD，窥视层继续更新。
[*]保留共享缓存和原生阴影，限制每帧区块更新量。
[*]版本／散列或资产检查失败时保留原生画法，最多记录警告。
[/list]

[h2]依赖与加载顺序[/h2]
Harmony → 配套 IsoRim → 本 Mod → 兼容模型包。
这是扩展框架，模型包需要提供并配置对应材质、法线贴图和各档模型。不会自动替换全部建筑、生成贴图或自动减面。仓库另附可选箱体示例包（44／28／12 三角面）。

[h2]当前范围[/h2]
支持范围为普通静态建筑，包括 IsoRimZ 地面与上层。车辆、活动炮塔、门叶及角色尚未验收。不包含完整 PBR、LOD 渐变过渡、阴影 LOD 或纹理卸载。减面不等于整局帧率提升，本 Mod 不承诺 FPS 或显存收益。

着色器由本子 Mod 维护。IsoRim 内部顶点属性、光照参数和裁切约定不保证稳定，更新后可能需要重新适配。
模型作者请阅读 MATERIALS.md、LOD.md、FLOORS.md 与 review/floor-validation.md。API 合并到 IsoRim 后，仍需更新本 Mod 的接口版本校验并重新验证。

[h1]English | IsoRim Material & LOD[/h1]
[b]Test build 0.3.0 · RimWorld 1.7[/b]

Adds baked normal maps and two- or three-level LOD to ordinary static building models in IsoRim. Normal maps represent grooves, seams, and small bevels; prepared simpler meshes are selected as you zoom out.

[b]READ BEFORE INSTALLING: This build requires the companion IsoRim API test branch. The standard Workshop build currently lacks the required APIs. Subscribing to this addon alone is insufficient. Follow the matching build and installation instructions in the source repository below.[/b]

[h2]Features[/h2]
[list]
[*]Normal maps for static buildings, with configurable strength and orientation.
[*]Two- or three-level LOD selected by screen size, with hysteresis to reduce threshold switching.
[*]Public IsoRim API integration, with no addon Harmony patches or private reflection.
[*]Supports static buildings on IsoRimZ ground and upper floors; enabling floors does not disable the extension.
[*]Screen-size LOD on the viewed floor, optional lowest LOD on visible lower floors, suspended LOD on hidden floors, and active LOD while peeking.
[*]Shared caches and native shadows are retained; section updates remain budgeted.
[*]Host/asset rejection retains native rendering with at most warning logs.
[/list]

[h2]Requirements and load order[/h2]
Harmony → matching IsoRim → this addon → compatible model packs.
This is an extension framework. Model packs must supply and configure materials, normal maps, and LOD meshes. It does not replace all buildings, generate textures, or simplify meshes automatically. The repository includes an optional crate example pack (44/28/12 triangles).

[h2]Current scope[/h2]
Supports ordinary static buildings, including IsoRimZ ground and upper floors. Vehicles, moving turrets, doors, and characters are not validated. Full PBR, LOD crossfading, shadow LOD, and texture eviction are not included. Fewer triangles do not guarantee faster gameplay; no FPS or VRAM savings are promised.

This addon owns its shader. Internal IsoRim vertex attributes, lighting parameters, and clipping conventions are not guaranteed stable; updates may require adaptation.
Model authors: see MATERIALS.md, LOD.md, FLOORS.md, and review/floor-validation.md. After the API is merged into IsoRim, this addon still needs updated API version checks and revalidation.
